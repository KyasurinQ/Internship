## 💼 Công việc đã thực hiện

### 1. Đọc tài liệu và hiểu toàn bộ chương trình ⏱️ 9:00 - 10:00

* Đọc toàn bộ tài liệu trong repo `Internship/` trên GitHub:

  * `worklog/`: Cách viết nhật ký hằng ngày, format markdown
  * `project-proposal/`: Các bước chuẩn bị proposal và ví dụ minh hoạ đồng
  * `blog-translation/`: Hướng dẫn dịch blog kỹ thuật cùng thuật ngữ chuyên ngành
  * `resources/`: Tổng hợp kiến thức AWS cơ bản, roadmap chứng chỉ
  * `templates/`: Các checklist để chuẩn bị bài nộp
* Hiểu rõ yêu cầu 3 deliverables chính: Worklog, Proposal, Blog dịch
* Lên kế hoạch cá nhân hoá workspace và phân bổ thời gian 8 tuần hợp lý

### 2. Tạo GitHub repository cá nhân ⏱️ 10:00 - 10:30

* Clone template repository và tạo repo riêng
* Thiết lập cấu trúc thư mục đúng chuẩn chương trình
* Tạo commit đầu tiên và cấu hình remote lên GitHub cá nhân

### 3. Tạo tài khoản AWS và đăng ký Portal Special Force ⏱️ 10:30 - 11:30

* Đăng ký AWS Free Tier bằng email cá nhân, xác minh danh tính
* Kích hoạt tài khoản thành công, được cấp \$300 credits dùng thử
* Đăng ký thành công trên hệ thống AWS Special Force Portal để theo dõi tiến độ

### 4. Thiết lập IAM User + MFA + AWS CLI ⏱️ 11:30 - 12:00

* Tạo IAM user với quyền `AdministratorAccess`
* Thiết lập bảo mật bằng MFA (ứng dụng Authenticator)
* Cài AWS CLI v2 trên máy và cấu hình credentials từ IAM user

### 5. Deploy Web API ASP.NET Core lên EC2 ⏱️ 13:00 - 15:00

* Tạo EC2 instance sử dụng Amazon Linux 2023
* SSH vào máy chủ bằng file `.pem`
* Cài đặt .NET runtime và ASP.NET Core runtime 8.0
* Dùng `dotnet publish` build project backend và upload qua `scp`
* Chạy app bằng `dotnet TruyenAWS2025.dll --urls "http://0.0.0.0:5000"`
* Mở port 5000 trong Security Group để truy cập API từ trình duyệt
* Kiểm tra truy cập thành công từ [http://54.226.186.253:5000/weatherforecast](http://54.226.186.253:5000/weatherforecast)

### 6. AWS Budgets & Cost Tracking ⏱️ 15:00 - 15:30

* Truy cập Billing Console trên AWS
* Tạo ngân sách \$5/tháng để kiểm soát sử dụng Free Tier
* Thiết lập cảnh báo qua email khi vượt 80% ngân sách

### 7. Viết Worklog và cố định cấu trúc dự án ⏱️ 15:30 - 17:00
