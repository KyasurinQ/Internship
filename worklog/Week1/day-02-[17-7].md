## 📃 Kiến thức học được

### 🔑 IAM vs ACL vs Bucket Policy

* IAM: Dùng cho user/role truy cập qua AWS API
* ACL: Quyền read/write cho từng file
* Bucket Policy: Quyền theo các rule json cấp bucket

### 📀 S3 đừng là bucket chứa file

* File trong S3 gọi là object (gồm key + metadata)
* Có thể truy cập bằng URL nếu public

### 🚀 Tính năng cao cấp

* Dùng Lifecycle để chuyển file sau 30 ngày vào Glacier
* Replication sang region khác cho backup
* Dùng S3 Lambda event trigger khi upload file
