## 📚 Kiến thức học được

### 🔧 Technical

* Cách **tích hợp AWS S3** với ASP.NET Core thông qua service interface (`IS3Service`).
* Quản lý **token authentication** khi call API bằng React + OIDC context.
* Cách đồng bộ frontend (React) và backend (C#) trong cùng một luồng upload avatar.
* Kinh nghiệm xử lý **fallback UI** khi dữ liệu bị null hoặc API trả về rỗng.

### 💡 Concept

* Tách biệt rõ **service layer (S3Service, UserService)** để dễ test & mở rộng.
* Hiểu được pattern “**Frontend gọi API get profile → Backend gọi Cognito & DB → trả JSON**”.
* User Page và Author Page thực chất dùng chung cấu trúc, chỉ khác data source.

### 🤝 Soft Skills

* Rèn kỹ năng debug cross-layer (Frontend ↔ Backend).
