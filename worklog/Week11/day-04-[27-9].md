   * Gặp lỗi CORS khi gọi ảnh từ S3 → phát hiện cần chỉnh CORS bucket.
   * Sau cùng: bỏ phần crop, chuyển về upload trực tiếp → hiển thị avatar luôn.

4. **S3 + CORS**

   * Viết file cấu hình CORS cho bucket (JSON).
   * Debug lỗi `ExposeHeader *` → sửa thành liệt kê cụ thể `ETag`, `Content-Type`.
   * Test với ảnh S3 trả về → vẫn gặp lỗi do CORS header chưa trả đúng.
   * Tìm hiểu phân biệt **Bucket Policy** (JSON) và **CORS Config** (JSON/XML).

5. **Debug lỗi**

   * Lỗi `Failed to execute 'toDataURL' on 'HTMLCanvasElement': Tainted canvases may not be exported.` → nguyên nhân: ảnh S3 không trả header CORS.
   * Lỗi `Access to image ... has been blocked by CORS policy` → cần chỉnh lại CORS.
   * Thử thêm `image.crossOrigin = "anonymous"` vào code crop.
   * Kiểm tra log `[object Event]` khi load ảnh thất bại → xác định root cause là thiếu `Access-Control-Allow-Origin`.

6. **Hoàn thiện flow upload avatar**

   * Người dùng chọn ảnh → `handleAvatarChange` upload API.
   * Backend upload lên S3 → trả về `avatarUrl`.
   * UI cập nhật avatar ngay lập tức.
   * Bỏ crop để tránh phức tạp & lỗi CORS.
