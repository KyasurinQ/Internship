### 2. Tạo RDS PostgreSQL ⏱️ 10:30–13:00

* **Mô tả**:

  * Tạo DB instance: `awswebtoon-db`
  * Chọn Free Tier (db.t3.micro, 20GB)
  * Bật Public access, sửa Security Group để mở cổng 5432
  * Lưu lại endpoint & credentials trong Secrets Manager

* **Kết quả**:

  * PostgreSQL sẵn sàng kết nối từ backend
  * Có thể quản lý user, profile, transaction

---

### 3. Kết nối .NET Backend với Database ⏱️ 13:00–16:00

* **Mô tả**:

  * Cấu hình `appsettings.json` với connection string RDS
  * Thêm **AppDbContext** cho EF Core
  * Chạy `add-migration` & `update-database` thành công
  * Cài AWS SDK để kết nối DynamoDB (`DynamoDbService`)

* **Kết quả**:

  * EF Core tạo bảng `Users`, `UserProfiles`, `Transactions` thành công
  * DynamoDB kết nối được qua AWS SDK
  * Có thể dùng cả 2 database song song mà không xung đột
