### 2. Test API với JWT Access Token ⏱️ 13:00–17:00

* **Mô tả**:

  * Dùng Swagger và `curl` để gọi API `/api/User/me` với access token từ Cognito.
  * Gặp lỗi **401 Unauthorized** với message:

    ```
    www-authenticate: Bearer error="invalid_token",error_description="The audience 'empty' is invalid"
    ```
  * Debug log trong ASP.NET Core:

    ```
    Auth failed: SecurityTokenInvalidAudienceException: IDX10231: Audience validation failed
    ```
  * Thêm `AudienceValidator` để kiểm tra `client_id` trong token.
  * Log ra claims trong token để phân tích.

* **Kết quả**:

  * Xác định được lỗi là do Cognito Access Token **không có `aud` đúng với `ClientId`**.
  * Cần custom lại `AudienceValidator` hoặc disable `ValidateAudience` để test tiếp.

## 📚 Kiến thức học được

### 🔧 Technical Skills

* Cách tích hợp AWS Cognito với ASP.NET Core Authentication.
* Phân biệt **ID Token** và **Access Token** trong Cognito:

  * ID Token → chứa `aud` = ClientId.
  * Access Token → chứa `client_id` nhưng `aud` có thể trống.
* Debug log với `Microsoft.IdentityModel.Logging` để phân tích token validation.

### 💡 Concepts & Theory

* **Audience validation**: xác định token có được phát hành cho đúng client không.
* Vì Cognito Access Token có `aud=empty`, cần tuỳ chỉnh lại validation.

### 🤝 Soft Skills

* Rèn luyện patience khi debug auth flow khá phức tạp.
* Kỹ năng đọc log và khoanh vùng nguyên nhân lỗi.
