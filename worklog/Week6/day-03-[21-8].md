* **Mô tả**:

  * Decode phần header của JWT token → lấy `kid`.
  * Fetch JWKS từ endpoint Cognito:

    ```
    https://cognito-idp.ap-southeast-2.amazonaws.com/ap-southeast-2_4m4YRPERj/.well-known/jwks.json
    ```
  * So khớp `kid` token với list JWKS.

* **Kết quả**:

  * Token có `kid = "0057XkwkIdpEOb1m3kZDd8TNh8aVX7af6kvwAE3xBHI="`.
  * JWKS chứa đúng `kid` này → **khớp thành công**.
  * Loại trừ được nguyên nhân “kid không match JWKS”.

    * `issuer` chưa đúng với Authority.
    * Hoặc `aud` bị empty nên middleware mặc định reject.

### 💡 Concepts & Theory

* **kid (Key ID)**: mỗi token được ký bằng private key tương ứng với public key trong JWKS. Nếu không khớp → 401 ngay.
* **401 không chỉ do signature**: còn có thể do issuer, audience, lifetime.
* **Manual validation** là cách hữu ích để phân biệt lỗi từ token hay do config.

### 🤝 Soft Skills
