### 1. Ôn tập Docker và thực hành Dockerfile ✔️

* Viết Dockerfile cho ứng dụng Node.js đơn giản (`hello world`)
* Build image và chạy container local bằng lệnh `docker build`, `docker run`

### 2. Tìm hiểu và thực hành Docker Compose ✔️

* Hiểu mục tiêu của `docker-compose` trong quản lý nhiều container
* Viết file `docker-compose.yml` gồm service app + MongoDB
* Thực hành build và run project bằng `docker compose up`

### 3. Cài Jenkins và tích hợp GitHub ✔️

* Cài đặt Jenkins local trên máy host
* Tạo job đơn giản, kết nối repo GitHub qua Webhook
* Thử cấu hình Job để pull code và in ra log build thành công

### 4. Học và thử nghiệm CI/CD pipelines ✔️

* Tìm hiểu các giai đoạn của một pipeline: build → test → deploy
* Viết pipeline đơn giản trong Jenkins để build Docker image từ GitHub repo
* Bắt đầu demo mini project: push image, deploy local bằng Docker Compose
