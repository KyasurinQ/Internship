🚧 Khó khăn và giải pháp
Vấn đề 1: ECS Task Definition Complexities

Mô tả: Cấu hình task definition (CPU, memory, ports) hơi phức tạp, dễ sai cú pháp
Impact: Mất thời gian debug khi task không chạy
Root Cause: Thiếu kinh nghiệm với JSON/YAML và ECS parameters
Solution: 
Dùng AWS Console wizard để tạo task definition ban đầu
Tham khảo sample task definitions trong AWS docs
Test incremental changes và kiểm tra logs


Result: Task definition chạy thành công, hiểu rõ hơn về cấu hình
Lesson: Bắt đầu với template đơn giản, dần dần thêm complexity

Vấn đề 2: Chưa quen với ECS Networking

Mô tả: Khó hiểu cách ALB tích hợp với ECS service và networking
Impact: Tốn thời gian cấu hình load balancer
Root Cause: Thiếu kiến thức về AWS networking (VPC, subnets)
Solution: 
Xem lại tài liệu về ALB và ECS service discovery
Dùng default VPC để đơn giản hóa setup
Thảo luận với mentor qua Slack để làm rõ


Result: ALB cấu hình thành công, ứng dụng accessible
Lesson: Cần học thêm về VPC và networking trước khi đi sâu vào ECS
