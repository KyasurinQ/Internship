### 2. Tích hợp Custom Attribute cho Cognito ⏱️ 13:00–15:00

* **Mô tả**:

  * Tìm hiểu cách thêm **custom attribute** `role` (User/Author).
  * Dùng AWS CLI để chạy lệnh:

    ```sh
    aws cognito-idp add-custom-attributes \
      --user-pool-id ap-southeast-2_4ZjLbaY6Q \
      --custom-attributes Name=role,AttributeDataType=String,Mutable=true,StringAttributeConstraints={MinLength=1,MaxLength=10} \
      --region ap-southeast-2
    ```
  * Verify bằng `describe-user-pool` → attribute đã được thêm.

* **Kết quả**:

  * Custom attribute `custom:role` đã có trong User Pool.
  * Có thể set thủ công bằng lệnh `admin-update-user-attributes`.

### 3. Viết Lambda PostConfirmation để gán group ⏱️ 15:00–17:00
