### 4. Debug lỗi 401 Unauthorized ⏱️ 15:00–17:00

* Sau khi fix URL, API trả về **401**.
* Phân tích nguyên nhân:

  * Backend yêu cầu **JWT token** (hoặc cookie session).
  * Frontend chưa gửi Authorization header → bị từ chối.
* Đưa ra hướng giải quyết: thêm `Authorization: Bearer <token>` khi gọi API, hoặc nếu dùng cookie thì bật `credentials: include`.
  ❌ **Kết quả**: Chưa gửi được token nên request vẫn bị 401.
  ✅ Nhưng đã xác định chính xác root cause → cần kết nối với hệ thống login (Cognito/Auth API).
