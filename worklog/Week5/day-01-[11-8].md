## 💼 Công việc đã thực hiện

### 1. Tạo AWS Account & IAM User ⏱️ 8:00–9:00

* **Mô tả**:

  * Đăng ký AWS Account bằng thẻ quốc tế, xác minh \$1
  * Tạo IAM User riêng cho môi trường dev với quyền `AdministratorAccess` ban đầu
  * Bật MFA cho cả Root và IAM User để tăng bảo mật
* **Kết quả**:

  * AWS Account sẵn sàng, IAM User login độc lập, giảm rủi ro khi sử dụng root account
* **Tools/Tech**: AWS Console, Authenticator App

---

### 2. Thiết lập AWS Budgets ⏱️ 9:00–10:00

* **Mô tả**:

  * Tạo 2 loại budget: tổng chi phí \$5/tháng và từng dịch vụ \$2/tháng (S3, DynamoDB…)
  * Bật Billing Alarms gửi cảnh báo qua email khi vượt ngưỡng
* **Kết quả**:

  * Chủ động theo dõi chi phí AWS, tránh bị vượt ngân sách khi dev/test
* **Tools/Tech**: AWS Budgets, Email Notifications

---

### 3. Cài đặt môi trường Dev ⏱️ 10:15–11:00

* **Mô tả**:

  * Cài AWS CLI, Git, Node.js, npm, VS Code

* **Tools/Tech**: AWS CLI, Git, Node.js, npm, VS Code
