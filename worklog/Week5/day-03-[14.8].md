## 💼 Công việc đã thực hiện

### 1. Tạo Cognito User Pool ⏱️ 8:00–12:00

* **Mô tả**:

  * Mở AWS Console → Cognito → Create User Pool
  * Chọn **Email làm username** để dễ quản lý
  * Bật **Self-registration** để user tự đăng ký
  * Bật **MFA (optional)** và chọn gửi OTP qua email
  * Tạo App Client (Web) và bỏ tick **Generate client secret** để frontend JS dễ sử dụng

* **Kết quả**:

  * Hoàn thành User Pool cơ bản
  * Sẵn sàng cho bước test đăng ký/đăng nhập

---

### 2. Tạo Groups và phân quyền ⏱️ 13:00–15:30

* **Mô tả**:

  * Tạo các nhóm role:

    * **Admin** → quyền cao nhất, quản lý toàn hệ thống
    * **Author** → quyền đăng truyện, xem dashboard tác giả
    * **User** → quyền đọc bình thường

* **Kết quả**:

  * Hoàn tất phân quyền cơ bản, chuẩn bị cho multi-role system
  * User Pool ID và App Client ID đã lưu lại để dùng frontend
