## 💼 Công việc đã thực hiện

### 1. Cài đặt và khởi động CloudWatch Agent ✔️

* Kiểm tra trạng thái agent, tạo config `toml`
* Dò lỗi khi `amazon-cloudwatch-agent.json` chưa tồn tại
* Tạo file config JSON `/opt/aws/.../amazon-cloudwatch-agent.json` theo schema chuẩn

### 2. Cấu hình gửi log về CloudWatch Logs ✔️

* Tạo log group `/var/log/messages`
* Gửi log từ file `/var/log/messages` về AWS
* Kiểm tra trên AWS CloudWatch Logs và xác nhận log stream hoạt động tốt
* So sánh config dạng `TOML` vs `JSON`

### 3. Cleanup & kiểm soát chi phí ✔️

* Dừng CloudWatch Agent bằng `systemctl stop`
* `disable` dịch vụ để tránh restart tự động
* Xóa log group nếu không còn dùng
* Hiểu sơ bộ về chi phí của CloudWatch Logs

## 📚 Kiến thức học được

### 🔧 Cấu trúc config CloudWatch Agent

* TOML: Cấu hình chi tiết theo kiểu `telegraf` (sử dụng khi dùng metric/log nâng cao)
* JSON: Dùng để fetch-config, dễ viết hơn cho beginner

### 🧩 Phân tích Agent components

* `inputs`: nơi lấy dữ liệu (logfile, mem, socket...)
* `outputs`: nơi gửi dữ liệu (CloudWatch, CloudWatchLogs)
* `processors`: xử lý trung gian
* `receivers`: nhận input và định kỳ gửi đi

### 🧠 Các lỗi thường gặp & cách xử lý

* Thiếu file `.json` → phải tự tạo đúng schema
* Phải dùng đúng log group name + stream name
* Nên kiểm tra log tại `/opt/aws/amazon-cloudwatch-agent/logs/...`
