### 3. Report System ⏱️ 13:00–17:00

#### 🔹 ReportContent (user báo cáo nội dung)

* **API**: `POST /api/Reports/report`
* **Kết quả**: User có thể gửi report với nội dung, loại vi phạm, id người báo cáo.

#### 🔹 GetReports (admin xem danh sách)

* **API**: `GET /api/Reports/all?page=1&pageSize=10`
* **Kết quả**:

  * Admin có thể xem danh sách report với filter: `status`, `contentType`, `q`, `from`, `to`.
  * Trả về dưới dạng `PagedResponse`.

#### 🔹 ResolveReport (admin xử lý báo cáo)

* **API**: `POST /api/Reports/{id}/resolve?status=Approved&adminId=xxx`
* **Kết quả**:

  * Admin thay đổi trạng thái report (`Approved`, `Rejected`, …).
  * Lưu lại ghi chú xử lý (`notes`).
